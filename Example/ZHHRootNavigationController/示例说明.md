### 1. 📵 禁用侧滑返回
**文件**: `Modules/禁用侧滑返回/ZHHDisablePopGestureController.m`

**功能展示**:
- 禁用全屏返回手势
- 禁用边缘返回手势
- 自定义触发区域（仅左侧30pt）

**核心代码**:
```objc

self.zhh_disableFullscreenPopGesture = YES;
self.zhh_maxAllowedInitialX = 30;
self.zhh_navigationController.zhh_enableInteractivePush = YES;
```

### 5. 🚀 Push 并移除当前页面
**文件**: `Modules/Push 并移除当前页面/ZHHPushAndRemoveViewController.m`

**功能展示**:
- Push到新页面后移除当前页面
- 适用于登录流程等场景
- 带完成回调的push方法

**核心代码**:
```objc
[self.zhh_navigationController pushViewController:homeVC 
                                          animated:YES 
                                          complete:^(BOOL finished) {
    if (finished) {
        [self.zhh_navigationController removeViewController:self animated:NO];
    }
}];
```

## 🔧 常见问题

### Q: 如何隐藏导航栏？
A: 设置 `self.zhh_navigationBarHidden = YES`

### Q: 如何禁用返回手势？
A: 设置 `self.zhh_disableFullscreenPopGesture = YES` 或 `self.zhh_disableEdgePopGesture = YES`

### Q: 如何使用自定义导航栏类？
A: 重写 `zhh_navigationBarClass` 方法返回自定义类

### Q: 如何移除导航栈中的某个页面？
A: 使用 `[self.zhh_navigationController removeViewController:vc animated:NO]`
